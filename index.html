About

I'm Jeanette. By day I'm an air traffic controller. By evening I build things with code — not because I was trained to, but because I wanted to see if I could.

I'm not a developer. I'm a builder who uses whatever tools get the job done: Claude, Supabase, GitHub, Netlify, and a lot of trial and error. Some of what I make works beautifully. Some of it breaks in ways I didn't know were possible.

This site is a record of that process — for me to track where I've been, and for anyone else who's starting from "I have no idea what I'm doing" and wants to see that you can get somewhere real from there.

fingo.digital — built by hand, deployed on Netlify, documented honestly.
